# Python Engineering

**Learning, building and documenting practical Python engineering skills.**

This repository documents my journey from Python-based analytics and scripting towards professional Python software engineering.

It focuses on writing code that is not only functional, but also reliable, testable, maintainable and reusable.

The repository contains practical implementations, exercises, experiments, code reviews and technical notes covering Python fundamentals and software engineering practices.

My primary areas of application include FinTech, banking, payments, data engineering and Applied AI/ML.

The repository is organised into six learning and implementation areas.

## Engineering Focus

The emphasis is on understanding and applying engineering principles rather than memorising syntax.

### Python Language & Runtime Behaviour
- Object model, references, identity and equality.
- Mutable and immutable objects.
- Assignment, shallow copy and deep copy.
- Functions, scope, closures and decorators.
- Iterators, generators and comprehensions.
- Data structures and algorithmic complexity.

### Application Development
- Modular Python applications.
- Object-oriented and functional programming.
- Input validation and configuration management.
- File handling and serialization.
- Database and API integration.
- Error handling and resource management.

### Software Quality
- Unit testing and test-driven development fundamentals.
- Debugging and systematic problem-solving.
- Type hints and static analysis.
- Logging and observability.
- Code reviews and refactoring.
- Performance and maintainability.

### Applied Engineering
Examples and exercises draw from practical scenarios such as:
- Payment and transaction processing.
- Financial data validation.
- Customer and account data processing.
- Data transformation pipelines.
- API integrations.
- AI/ML application components.

## Learning Through Implementation

The repository follows a practical progression:

1. Understand Python behaviour and existing code.
2. Implement concepts through focused exercises.
3. Test assumptions and investigate edge cases.
4. Debug and improve implementations.
5. Combine concepts into progressively larger applications.
6. Apply appropriate engineering standards.

Code examples are accompanied by comments and explanations where they add learning value.

The intention is to make the repository useful both as a practical reference and as a record of continuous technical development.
